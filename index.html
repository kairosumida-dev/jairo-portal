      ACESSO PRIVADO POR CONVITE

      Criar Conta no JaiRO

      Seu cadastro entra na fila segura do Cofre (GitHub Vault) ou direto no Host ativo. Quando você abrir o Jogar.bat, sua conta já estará sincronizada no servidor.

      Configuração Opcional: Envio Direto ao Cofre GitHub (kairosumida-dev/jairo-vault)

      Se quiser que este navegador envie o ticket direto para o repositório privado sem precisar baixar o arquivo, cole um Fine-Grained Token com acesso apenas a kairosumida-dev/jairo-vault (fica salvo somente neste navegador).

      FLUXO DO PRIMEIRO LOGIN

      Como funciona na prática

      1. Preencha os dados ao lado e envie seu cadastro.
      2. O site tenta entregar primeiro ao Host ativo local e/ou ao repositório privado jairo-vault. Se estiver offline sem token, baixa um ticket JSON pronto para o Jogar.bat importar.
      3. Quem abrir o Jogar.bat primeiro assume como Host (via Epic EOS P2P), baixa a fila do GitHub Vault e injeta as contas novas no MariaDB antes do jogo abrir.
      4. Se outro amigo já estiver hosteando, o daemon dele checa a fila a cada 15 segundos e cria sua conta automaticamente.
